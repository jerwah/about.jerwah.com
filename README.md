## Use of AI in Coding

Let's face the facts: artisanal, hand-crafted code is fun and important to know how to do, but much like retro computers, which are also fun to dust off and play some Impossible Mission on, you're just not going to try to run your business on a C=64 either. So I use AI as a tool. It helps me get the dull stuff done, fast. It makes my documentation light years more useful. I still crack my knuckles over my shiny new Model-M (clicky keys for life) to hammer out a core concept, but then use the tools to bring it from "close enough" to "pretty good". I completely understand why people hate it, but we don't cut rock with sand and rope anymore. We found better tools.
